# Предсказание эффективности маркетинговой кампании
## Описание проекта
Этот обучающий проект наглядно демонстрирует все этапы решения классической задачи классификации в Data Science — от первичного анализа данных и предобработки признаков до подбора моделей, борьбы с дисбалансом классов и оценки качества.

## Цель
Цель проекта — на практике отработать полный цикл решения задачи бинарной классификации в Data Science: от анализа исходных данных и предобработки признаков до выбора и сравнения моделей, подбора способов борьбы с дисбалансом классов и интерпретации результатов.

## Задачи

### Файл baseline.ipynb — база и первичный анализ:

* проверка качества данных и аудит на ошибки;
* изучение распределения признаков и таргета, анализ взаимосвязей;
* препроцессинг: обработка пропусков, кодирование категориальных переменных, унификация типов;
* построение базовой модели и расчёт метрик — фиксация стартового уровня качества.

### Файл improvements_cv.ipynb — улучшения и валидация:

* тестирование преобразований данных и новых признаков;
* оценка эффективности через кросс‑валидацию;
* отбор только тех улучшений, которые стабильно повышают метрики.

## Для кого
Проект носит обучающий характер — его цель не в достижении максимальной точности любой ценой, а в системном освоении типовых шагов и распространённых подводных камней при построении классификационных моделей.
